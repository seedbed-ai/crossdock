The current Codex browser adapter only advertises implementation, and that path remains experimental until authenticated compatibility testing verifies it. Disabled intents are represented by the core model but are not executable through this browser surface yet.

The browser adapter connects only to an HTTP loopback service on 127.0.0.1. Change this when running the local service on a different port.

Evidence settings control the durable task record. Crash recovery is separate: memory-only prevents that plaintext from being written to browser local storage. After a restart, full or hash evidence cannot be completed if the required original bytes were intentionally discarded. Reports are only affected after capture.

Committed-file provenance is optional. Enabling it requires an explicit repository, branch, and path template containing {task_id}; no destination is inferred. Publication is separate from task-record storage. These choices are frozen when a task starts.
